# 自行车 · 手动骑行模拟器

一个可运行于桌面与手机横屏浏览器的 3D 自行车原型。骑行的全部进步来自玩家对踩踏、车把、身体和落脚的掌握。默认第一人称与辅助轮难度，无任务、无数值成长。左上角显示实时速度与本段骑行距离，调试数据默认关闭。

[在线试玩](https://baolilinglan.github.io/bicycle-simulator/)

## 运行

需要 Node.js 22.12 或更新版本，以及支持 WebGL 2 的现代浏览器。手机横屏后自动启用触屏控制。

```sh
npm ci
npm run dev
```

打开终端显示的 `http://127.0.0.1:5173/`。Windows 也可以双击 **启动游戏.cmd**。按“开始骑行”后，浏览器会捕获鼠标；Esc 释放鼠标并暂停。嵌入式浏览器禁止鼠标捕获时，可在独立 Edge / Chrome 浏览器打开同一地址。

```sh
npm run build       # 类型检查及生产构建，输出 dist/
npm run preview     # 本地预览生产构建
npm test            # 固定步长物理回归测试
npm run test:browser # 先运行开发服务器；通过本机 Edge 执行桌面交互测试
npm run test:comfort # 难度、惯性、音乐播放与完整改键交互
npm run test:practice # 回起点、骑行距离、踩踏提示、刹车手势与路面
npm run test:mobile  # 触屏、多指操作、横竖屏和多分辨率测试
npm run test:production # 先构建；验证生产文件在 GitHub Pages 子目录的加载
```

人物使用 Blender 制作的原创骨骼模型，源文件为 `assets/rider/commuter.blend`，运行时加载经过 Meshopt 压缩的 `public/models/rider.glb`。地形和机械声音由代码生成。字体使用系统本地字体，运行时无需外部 CDN。

上传与公开试玩页部署见 [GitHub 发布指南](GITHUB发布指南.md)，已附带自动测试、构建及部署工作流。

## 难度、速度表与音乐

主菜单和设置都能切换难度，切换时会原地重新摆正，并记住选择：

| 难度 | 说明 | 手感 |
| --- | --- | --- |
| 辅助轮难度（默认） | 体验有辅助轮的畅快自行车生活 | 两个可见的辅助轮通过地面接触支撑车身；双脚初始在踏板上，直接交替 Q / E 起步 |
| 平衡练习难度 | 轻松起步，慢慢找到平衡 | 无辅助轮；加入有限的平衡力矩和摆动阻尼。蹬地输入可提前 0.7 秒，起步后自动收脚 |
| 暴力铃兰难度 | 体验暴力铃兰骑自行车的痛苦 | 保留原始无辅助物理，手动蹬地、收脚与维持平衡 |

两个较低难度只在踏板向下行程接受踩踏力量，减少误按带来的卡顿。最高难度仍保留错误踩踏相互抵消与单脚死点行为。

速度表显示刚体实际水平速度（km/h），包括后退和侧滑。松开踏板后，飞轮允许滑行；空气阻力、轮胎滚阻、坡度和独立刹车共同改变速度，没有松键即停的逻辑。

背景音乐使用用户提供的 **Keep It Straight**，本地文件为 `public/audio/keep-it-straight.mp3`。进入骑行后循环播放，暂停、操作弹窗和页面切到后台时暂停，继续骑行时从原处续播。音乐开关、音乐音量与机械音效音量分别保存。

## 骑行辅助与练习场

按 T 一键回到起点，也可以点击“起点”按钮。此动作同样支持改键。本段距离累计车轮接地时的实际水平移动，摔倒或回到起点后清零；原地摆正保留本段距离，倒地滑行与重置位移不计入。

设置中的“踩踏提示”控制左右脚的发力窗口、落脚状态与轻微提示音，随实际键位更新。刹车时对应手指与刹把收紧，蹬地和路面颠簸带来小幅身体反馈。

练习场增加贯通直路、缓弯、坡道与窄路的闭合路线，以及八字转弯区和停车区。碎石、草地、湿滑路面有不同的滚阻、抓地力、细微振动和声音，没有随机事故。

标题由内置 imagegen 生成，透明图片位于 `public/images/bicycle-title.png`，最终提示词见 [Logo 生成记录](assets/branding/logo-prompt.md)。主菜单包含入场、轻微浮动、悬停和扫光动效，支持系统“减少动态效果”设置。

## 默认操作

| 输入 | 动作 |
| --- | --- |
| Q / E | 左 / 右脚向下发力；该脚落地时，单次按下可蹬地 |
| 鼠标左右 | 改变车把位置，松开移动不会自动回中 |
| A / D | 身体向左 / 右移动 |
| W / S | 身体向前 / 后移动；W 不提供驱动力 |
| Z / C | 左 / 右脚落地或收回踏板，按一次切换 |
| 鼠标左 / 右键 | 前刹 / 后刹，按住逐渐建立刹车力 |
| 鼠标上下 | 俯仰视线 |
| 空格 | 暂时低头看车身与踏板 |
| V | 第一 / 第三人称切换 |
| R | 原地重新摆正；辅助轮模式双脚回踏板，其他模式左脚支撑 |
| T | 回到起点，同时清零本段骑行距离 |
| H | 显示 / 收起按键提示弹窗 |
| Esc | 暂停、设置、回到起点 |
| F3 | 开关物理调试数据，初始关闭 |

设置 → 键位设置可修改所有动作，包括前后刹车、暂停与可选的键盘车把 / 视线控制。点击动作右侧后，按键盘或鼠标按键；重复绑定会交换，Delete / Backspace 清除，Esc 取消。支持恢复默认并在本机保存。Esc 始终保留为暂停出口，Tab 和系统 Meta 键不绑定。

手机横屏时，左侧圆盘调整重心，右侧圆盘左右滑动车把、上下调整视线。中间按钮分别控制两只踏板、两只刹车与双脚落地，支持多指同时操作。切到竖屏会暂停；横屏后点击继续骑行。首次进入骑行会显示操作弹窗，也可随时点击“操作”重新查看。

### 最高难度的起步与停车

1. 初始左脚在地面支撑、右脚在适合发力的位置。
2. 轻按 Q 蹬地，同时用 E 踩下右踏板。
3. 用 Z 收起左脚，交替 Q / E。踩到底后放开该键，换另一脚。持续按同一键会在下止点停滞，同时按住双键则相互抵消。
4. 低速时用身体重心抵消倾倒，并把前轮轻轻转向车身正在倒下的一侧。速度越高，修正幅度越小。
5. 停车时 S 将重心后移，配合两只刹车，接近停止前用 Z / C 伸脚。脚仍是弹性接触，不会锁住车身。
6. 失去平衡后随时按 R 重新尝试，没有失败界面。

## 实现结构

- `src/physics/bicycle.ts`：六自由度 Rapier 刚体、两处轮胎接地、曲柄和单向飞轮约束、移动重心、落脚接触、独立刹车、摔倒刚体与球关节。
- `src/physics/world.ts`：120 Hz 固定物理步长、地面、坡道、低路缘、动态路锥。坡面碰撞与渲染共用顶点。
- `src/render/`：Three.js 渲染、自行车模型、Blender 骨骼角色与手脚双骨 IK、第一 / 第三人称相机、练习场。
- `src/input.ts`：输入映射、鼠标捕获、失焦清理、设置持久化。
- `src/audio.ts`：动态机械音效与独立 BGM 混音、循环和暂停续播。
- `src/difficulty.ts`：三个难度的名称、说明和类型。
- `src/ui/`：开始、操作弹窗、设置、触屏控制、响应式布局及悬停 / 按压动效。
- `tests/`：物理行为和浏览器交互验证。浏览器截图位于 `test-results/`。

### 物理模型边界

这是以操作学习为目标的近似物理原型，尚不是经过真实自行车测量校准的工程仿真。

正常骑行中，车架和骑手共享一个自由动态刚体；身体输入改变这个系统的质量中心。每只车轮有独立的旋转惯量、角速度、制动力和轮胎接触冲量。轮子不是两个独立的铰链刚体；轮胎采用射线接地和摩擦圆近似，窄轮胎碰撞壳处理路缘、墙壁等障碍。前后轮负载自然参与摩擦极限和刹车俯仰。

最高难度车身没有“恢复竖直”的控制器。三个模式都不直接设置骑行速度或转向后的姿态。重力、两轮接地点、轮胎侧向冲量、移动重心和角速度阻尼共同决定平衡。少量随速度变化的角速度阻尼和机械拖曳效应用于约束过快的变化，不会将倾斜角归零。中等难度显式加入有限的倾斜辅助力矩，仅在轮胎接地时生效，并跟随转弯所需倾角；辅助轮难度通过两侧支撑轮的弹性接触、横向摩擦与障碍碰撞提供支撑。测试中的反馈骑手只存在于测试文件中。

落脚用单向弹簧、阻尼和摩擦表示腿的支撑。摔倒时骑手切换为七个球关节连接的刚体，由物理求解器处理倒地，不播放摔倒动画。这些接触、关节和声音仍可继续做实机手感与写实程度调校。

坐标约定：米、秒、千克；+Y 向上、+Z 向前，因此 +X 是骑手左侧。内部正倾斜 / 正转向角表示左侧，输入层已将鼠标右移和 D 映射到正确的右侧。

## 已验证

18 项固定步长回归测试覆盖：单脚支撑、无支撑自然倾倒及重置清理、单脚死点与交替驱动、W 不驱动、蹬地、前后刹车差异、前刹负载转移 / 后轮离地、后轮滑移、高速急转倾倒、空中转动车把不会直接旋转车身、可控的连续骑行、坡道减速、低路缘碰撞和多次摔倒后的资源清理。连续流程测试通过玩家输入完成起步、收脚、加速至约 18 km/h、制动和双脚接地停车。新增测试验证辅助轮停车支撑、直接踩踏起步、滑行惯性、刹停、中等难度提前蹬地与自动收脚，以及反复切换难度的碰撞体清理。本次另验证骑行距离与重置语义、踏板状态、不同地面材料和闭合路线几何。

浏览器测试检查真实键盘起步、第一人称低头、骨骼模型加载、第三人称、操作弹窗、按钮动效、暂停、设置保存、自然摔倒、重置与键位修改。移动端模拟测试覆盖多指踩踏、同时刹车转向、触摸取消清理、横竖屏切换，以及 568 × 320 至 2560 × 1080 的 8 种窗口尺寸。舒适性测试验证三档难度、真实 MP3 解码播放、暂停续播、音乐开关、速度表和键鼠改键持久化。生产测试验证仓库子目录下的模型、BGM、Logo 与页面资源加载，以及减少动态效果、距离累计和回到起点。练习测试覆盖提示开关、回起点改键、刹车手指独立运动与路面识别。移动端测试采用浏览器触屏模拟，尚未覆盖各种真机 GPU 与长期骑行手感。

物理接口使用方式参考 [Rapier 刚体文档](https://rapier.rs/docs/user_guides/javascript/rigid_bodies/) 与 [场景查询文档](https://rapier.rs/docs/user_guides/javascript/scene_queries/)。
